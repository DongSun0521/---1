# Combat V2-8G：高等级行动频率加固

## Debug人工验证入口

Debug/编辑器运行正式主场景时，顶部“开发战斗入口”新增
`V2-8G Lv.50高等级节奏验证（不结算）`。该入口使用冻结的
`v2_7b_three_archetype_full_battle`与固定种子2703，并通过现有Preview Host、
Router和请求契约启动。四名角色由CharacterDatabase、Stage 12正式等级成长和
正式V2尺度适配器构造成独立纯数据快照，运行ID使用`v2_8g_lv50_*`前缀，不读取
或冒充CharacterRoster中的正式角色。

该模式严格属于不结算预览：胜利、失败和中止均不打开Settlement Service，
不写经验、奖励、伤情、远征、资源、临时货物或存档。Release策略下不会创建
入口控件、占位、快捷键或相关文字。调试摘要会列出正式原始攻速、参考攻速、
原始比例、曲线倍率、最终行动间隔和0.20秒安全下限状态。

本阶段只加固正式属性进入V2实时战斗时的行动频率映射。V2总开关仍默认关闭且不持久化；
本阶段不表示可以正式开放V2，也没有修改角色成长、装备、村庄、料理、伤情、V1战斗、
冻结V2基准、怪物、波次或大招数值。

## V1真实语义与正式来源审计

V1的`BattleSystem`每轮为每个存活单位生成一次行动，`speed`只决定该轮行动顺序；
`attack_speed`不会被V1行动循环读取。因此正式攻速是沿角色数据保留的旧属性尺度，不能
直接解释为每秒攻击次数。

正式最终属性由`CombatCharacterData.calculate_final_stat_details()`统一合成。当前各来源对
`attack_speed`的实际影响如下：

| 来源 | 当前是否改变攻速 | 说明 |
|---|---|---|
| 职业基础 | 是 | 战士3、游侠7、法师5、医生6 |
| Lv.1～50成长 | 是 | 游侠和医生每级+1；战士、法师每级+0 |
| 装备 | 否 | 装备只有攻击、防御、生命、`speed`，没有`attack_speed` |
| 村庄 | 否 | 当前只提供攻击和生命加成 |
| 伤情 | 否 | 当前只将最大生命乘以0.8 |
| 远征料理 | 否 | 当前只提供攻击或临时最大生命 |
| 特性及其他临时修正 | 否 | 当前正式调用没有传入攻速修正 |

所以现有正式系统合法生成的攻速范围按职业分别为：战士3、游侠7～56、法师5、医生
6～55。缺失、0、负数、NaN或Infinity不属于合法值，V2接入边界会明确拒绝。装备、村庄、
伤情和餐食组合不会进一步提高这些上限；未来若正式系统合法扩展了攻速来源，仍会经过同一
曲线和0.20秒安全下限。

## 递减收益公式

公式集中在`FormationDefenseStatScaleAdapter`，职业差异只来自既有正式职业参考攻速和
实时读取的冻结V2职业基准间隔，没有角色ID或战斗ID判断。

```text
r = 正式最终攻速 / 正式职业参考攻速

r <= 1：
  行动频率倍率 m = r

r > 1：
  x = r - 1
  m = 1 + 2x / (2 + x)

未保护间隔 = 冻结V2职业基准间隔 / m
最终间隔 = max(0.20秒, 未保护间隔)
```

参数集中定义为：参考倍率1、最大频率倍率3、超出参考部分的半饱和宽度2、绝对安全下限
0.20秒。曲线在参考点数值和一阶斜率连续：参考属性严格返回倍率1；低于参考时保持直观
比例；高于参考时初段仍有正常收益，随后逐渐趋近3倍。安全下限只负责异常扩展时的最后
保护，不是高等级平衡的主要规则。

调试尺度报告会显示正式原始攻速、职业参考攻速、原始比例、曲线后倍率、最终间隔及是否
触发安全下限。该报告只进入已有Debug诊断文字，Release不创建或显示公式诊断。

## Lv.1、Lv.50与当前合法上限

当前合法最高攻速就是Lv.50基础成长结果，因为其他正式来源不修改`attack_speed`。

| 职业 | Lv.1/参考攻速 | 冻结间隔 | Lv.50/最高攻速 | 原线性间隔/频率 | 新间隔/频率 |
|---|---:|---:|---:|---:|---:|
| 战士 | 3 | 0.80秒 | 3 | 0.800秒 / 1.250次每秒 | 0.800秒 / 1.250次每秒 |
| 游侠 | 7 | 0.65秒 | 56 | 0.081秒 / 12.308次每秒 | 0.254秒 / 3.932次每秒 |
| 法师 | 5 | 1.10秒 | 5 | 1.100秒 / 0.909次每秒 | 1.100秒 / 0.909次每秒 |
| 医生 | 6 | 0.75秒 | 55 | 0.082秒 / 12.222次每秒 | 0.288秒 / 3.475次每秒 |

参考属性的生命、攻击/治疗、范围和行动间隔完全不变。Lv.50游侠与医生均高于0.25秒目标；
全部当前合法组合高于0.20秒安全线。

## 运行与压力验证

`tools/smoke_v2_8g_action_frequency_hardening.gd`覆盖参考点、连续性、单调性、递减收益、
Lv.1/Lv.50、所有当前正式修正来源、非法输入和安全下限。它还使用正式四职业Lv.50纯数据
快照经正式Party Source、请求构建器和V2 Host完整运行两次。

固定压力结果两次一致：65.1秒VICTORY、60生成/60击杀/0漏怪；游侠实际间隔
0.254348秒并行动59次，医生实际间隔0.287736秒。由于高等级伤害会由游侠快速清场，医生、
战士和法师在该样本中没有取得合法行动目标，这属于正式数值结果而非测试注入。活动弹体
峰值1，终局残留0；没有同帧无限行动、计时器饥饿、会话残留、重复终态、存档写入或
Godot崩溃。

V2-8C-R当前参考队伍仍严格使用倍率1，因此无人203.1秒失败与固定操作180.8秒胜利的
冻结结果不变。V2-7B、V2-5C、V2-3及V1历史基线也必须继续通过后才能进入人工验收。
